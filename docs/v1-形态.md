# 第一形态

当前要做的唯一形态。观众在自己电脑上看英 / 日 / 韩直播，把听到的话译成简体中文，叠在屏幕上。只用本机听译，不连我们的服务器。不是给主播往画面里叠字幕用的。后面的形态见 [后续.md](./后续.md)。

词见 [CONTEXT.md](../CONTEXT.md)。决定见 [adr/](./adr/)。听译在观众本机。代码在 `desktop/`。产品稿在 `chanpin/desktop/`。

## 观众怎么用

1. 产品在托盘。图标钉在通知区能看见。
2. 点托盘打开控制面板，选一个音源（正在出声的应用程序，或系统混音），按开始。
3. 字幕窗出现：置顶、透明、没有按钮。字穿透，点到的是下面的直播。可拖、可改大小。默认屏幕靠下居中，离开底边一截。
4. 要停，在控制面板按停止，字幕窗撤掉。点面板 × 只是把面板藏起来。从托盘退出才整份关掉。

开机自启默认关。勾了也只把产品拉到托盘，不会自动开听。音源、字幕模式、窗的位置下次还在；上次那个进程不在了，停在控制面板里再选，不改成系统混音。

## 屏幕上是什么

同一时刻只亮当前一条字幕条。双语时原文一行、译文一行，仍算一条。默认双语，可改成仅原文或仅译文。

当前条先出草稿，切条时定稿。下一条来了立刻挤掉上一条，不淡出。没有下一条时，约两秒后直接撤掉。

没有「在听但字幕藏着」这种状态。字幕窗上没有叉、没有工具条。

## 第一形态不做

- 不给主播往直播画面里叠字
- 不拆同一个浏览器里的两个标签
- 不让观众调切条快慢
- 不配音
- 源语言不锁死，自动认；MVP 只认英、日、韩 → 简体中文
