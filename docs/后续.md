# 后续（未做）

本机听译见 [v1-形态.md](./v1-形态.md)，已能用。托管听译已实现，见 [hosted-listen-spec.md](./hosted-listen-spec.md) 与 [v2-形态.md](./v2-形态.md)。

## 托管听译

已实现（分支 `feat/hosted-listen-captions`，含账号、顶号、满员、改密码；测试全绿，待部署验证）。同一套壳，选托管则把声音送到我们这边。网络不好可以改回本机；被顶或断网不偷偷切本机。

## 浏览器插件

不做。音源是进程，插件只能抓标签页，吃不到 TikTok 桌面端。以后若单独做「只看网页直播」，再另开一页，不和这个客户端混。

## 移动端

未立项，倾向安卓先。语义已定：多端登录、一路在听、跨端顶号（ADR 0033）。产品原型草稿在 `chanpin/android/prototype/`（可交互、扔掉用，表达形态不等于立项）。立项的先决条件是真机抓音验证——安卓上 MediaProjection + AudioPlaybackCapture 能否抓到目标直播 app 的声音，抓不到就不立项；验证要在托管服务封顶之后做。Mac 排安卓后：壳跨平台，新增只有 ScreenCaptureKit 抓音和签名公证。iOS 不做：第三方拿不到其它 app 的音频，也做不了全局字幕，两个核心动作都被系统禁掉。
