# 安卓音源模型：整屏授权一次，面板内按 App 过滤，交互对齐桌面端

开听走一次「整块屏幕」的 MediaProjection 授权（createScreenCaptureIntent 不指定单 App）；
之后主面板像桌面一样列出正在出声的 App（音源），`addMatchingUid / excludeUid` 在采集配置层过滤，
换音源不再弹系统授权框；「全部可抓的声音」= 不加 UID 过滤，对应桌面「系统混音」。
`excludeUid(本人)` 默认开（spike 实测抓取流含自己 App 的声音）。

没选的另一条路：授权时用系统单 App 选择器（API 34/35 原生支持）。它系统级精确，但换音源要重走系统弹窗、
与桌面「面板点一下就换」的音源模型割裂，且「全部声音」兜底仍得换整屏授权。选整屏+面板过滤保住了
CONTEXT 词表「音源」的跨端一致语义；代价是「整个屏幕」的授权文案偏重，需要产品文案说明
「只推匹配的声音、不录画面、不落盘」来安抚。对方 App opt-out 表现为静音，用能量检测给「这个 App 不让抓」提示（可行性调研已定）。

关联：0001（桌面音源按进程选）、0035（安卓栈）、0036（算力全托管）。
