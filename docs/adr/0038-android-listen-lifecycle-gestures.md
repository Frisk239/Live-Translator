# 安卓端在听的生命周期边界：锁屏停、划掉退、返回藏

在听的结束动作全清单（与桌面「点 × 藏面板、托盘是锚点」对齐）：

- **返回键 / 切到别的 App**：藏，在听继续（mediaProjection 前台服务 + 悬浮字幕照常）。对应桌面点 ×。
- **常驻通知**：在听状态的锚点，点通知体回控制面板，带「停止」按钮。对应桌面托盘。
- **划掉最近任务**：停听并退出——撤悬浮窗、断推流、清通知。桌面无对应。
- **锁屏**：停听（Android 15 系统自动停录，顺势而为；语义已入 CONTEXT「开听」词条）。

反惯例点与理由：音乐类 App 划掉后前台服务续播；我们选择划掉即停——悬浮字幕窗依赖「观众还在看直播」的场景，
划掉后仍飘在别人直播上的字幕是关不掉的孤儿窗，体验更差；而「切走再回来」是任务切换，不误伤。
来电 / 抢音频焦点场景无需新语义：直播 App 暂停期间 AudioPlaybackCapture 读到的是静音 PCM，
持续推流下服务端不会空闲超时（空闲超时只当断线用），电话回来字幕无缝继续。

关联：0027（凭据）、0019（断线重开）、0033（跨端一路在听）。
