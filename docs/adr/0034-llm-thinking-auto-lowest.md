# 思考强度不暴露给观众：自动探测，自动最低档

控制面板只让观众选模型。不同 OpenAI 兼容接口控制思考的参数名不一（reasoning_effort / enable_thinking / thinking……），这层差异由壳在后台消化：拉模型成功后自动探测接口认哪个参数、有哪些值，挑「思考最少」的一档（完全关闭优先，最低档次之）写进本机存档，观众无感。没探测到也不吃接口默认——默认可能是重度思考，与「听译要快」相反——先按最通用的 `reasoning_effort: low` 发，接口不认由 400 兜底去掉该字段重试。「不发送思考字段」从隐式默认降级为最后兜底，不再是观众可选项；面板上不再出现思考字段和探测按钮。
