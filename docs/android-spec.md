# 安卓客户端（第一版）

## Problem Statement

观众在手机上看外语直播时想要中文字幕叠在直播画面上。手机端不做本机听译：性能与发热不允许在端上跑「识别+翻译」（ADR 0036 调研），手机只抓音、出字幕，听译全在托管服务。账号、顶号、满员、断网、字幕条规则全部沿用桌面端已定语义，跨端一致（ADR 0033）。

## Solution

Kotlin + Compose 原生（ADR 0035）。App 三层对应桌面「托盘 + 控制面板 + 字幕窗」：控制面板（Compose，登录/选音源/开听/个人中心）、监听前台服务（mediaProjection 类型，抓音 + WS 推流）、悬浮字幕窗（View + WindowManager，可拖、样式可调）。音源模型与桌面一致（ADR 0037）：整屏授权一次，面板按 App 过滤。生命周期边界（ADR 0038）：返回藏、通知锚点、划掉停听退出、锁屏停听。

## User Stories

1. As a 观众, I want 首启看到一页引导说明（录音=抓声音、通知=在听状态、悬浮窗=字幕叠在直播上）并一次性授权, so that 一次讲清之后永不再被打扰
2. As a 观众, I want 未登录点开听时整页换登录/注册, so that 和桌面同一体验
3. As a 观众, I want 在面板里从正在出声的 App 里选一个当音源或选全部可抓的声音, so that 和桌面选音源一样
4. As a 观众, I want 按开听只过一道系统投屏授权（每会话一次）然后留在面板看字幕浮窗出现, so that 开听流程最短、不被替我做切换
5. As a 观众, I want 字幕条规则和桌面完全一样（草稿长字→定稿→切条挤压→静默约两秒撤条、双语可切）, so that 观感不因换端而变
6. As a 观众, I want 悬浮字幕可拖、颜色字号可调、位置拖到哪记到哪、可一键回默认、点一下回面板, so that 字幕长在我要的地方
7. As a 观众, I want 锁屏即停听、解锁回来面板一键重开, so that 不白占托管名额也不丢状态
8. As a 观众, I want 划掉最近任务等于停听退出、返回或切走只是藏, so that 关就是关、藏就是藏
9. As a 观众, I want 常驻通知显示在听状态并带停止按钮, so that 随时能停不迷路
10. As a 观众, I want 来电或直播暂停期间字幕停住、回来无缝续, so as not to 被踢出在听
11. As a 观众, I want 同一账号手机电脑互顶（被顶横幅说明、不自动重开）、多端可同登, so that 一路账号只占一路听译
12. As a 观众, I want 满员/断网/登录失效各有横幅说明（断网短闪断自动再开、重试尽停听）, so that 每个终态都有人话
13. As a 观众, I want 对方 App 不让抓时得到「这个 App 不让抓」的提示, so that 静音不让我对着空白发呆
14. As a 观众, I want 勾记住我则重开免登录、不勾则划掉即登出, so that 和桌面的记忆语义一致
15. As a 观众, I want 个人中心改密码（其它端登出、本机保登录）和退出登录, so that 账号在自己手里

## Implementation Decisions

- 栈：ADR 0035——App 内界面 Compose，悬浮字幕窗 View + WindowManager，mediaProjection 前台服务；抓音/推流/字幕窗全是 Android 私有 API，无跨端框架。
- 算力：ADR 0036——端上零听译算力，仅保留 VAD/能量检测（「不让抓」静音提示）。无本机听译档位、无离线模式。
- 音源：ADR 0037——开听走一次「整块屏幕」投屏授权；面板列正在出声的 App（addMatchingUid / excludeUid 在采集配置层过滤），换源不重授权；「全部可抓的声音」= 不过滤；excludeUid(自己) 默认开。
- 生命周期：ADR 0038——返回/切走=藏（在听继续）；常驻通知=锚点+停止；划掉=停听退出；锁屏=停听（CONTEXT「开听」词条）。来电/抢焦点/直播暂停：持续推流下静音也是 PCM，服务端空闲超时只当断线判定，无需打断处理。
- 权限：首启集中申请——一页引导后依次：录音+通知（系统弹窗）、悬浮窗（跳系统设置，返回自动检测）；投屏授权每会话一次、由开听动作触发（系统硬约束，token 不复用）。授权完留在面板，不代用户切换 App（修订原型「自动跳看播」）。
- 凭据：照搬 ADR 0027 语义（记住我跨次、不勾进程死即掉、改密码换发 token），载体 Android Keystore。
- 缝协议：复用托管听译缝（auth → start → f32le/mono/16k PCM → draft/final/notice），链路已由 spike 端到端实测（android/README.md 清单 #1b）。
- 通知/横幅文案、改密码布局、字号颜色档位具体值：开发中定，不阻塞架构。
- 字幕在本产品自己的界面里藏起来：沿用原型建议，开发中可调。

## Testing Decisions

- 缝行为测试移植桌面假听译思路：回放原型时间轴验草稿/定稿/撤条与顶号/满员/断网横幅。
- 音源过滤（按 App / 全部 / 排除自己）、静音检测提示、锁屏停听、划掉退出：模拟器可测（spike37 流程已跑通）。
- 真机闸门清单（抖音/B站/TikTok、锁屏、撤销授权、再授权）独立跟踪：android/README.md。
- 端到端链路（抓音→推流→托管→字幕回显）已由 spike 实测闭环，正式客户端沿用同一缝。

## Out of Scope

本机听译与任何离线模式（ADR 0036）、iOS（后续.md）、浏览器插件形态、热更新、多账号切换、推送、账单、主播向叠字幕。
