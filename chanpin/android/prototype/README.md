# 直播同传 · 安卓可交互原型（扔掉用）

回答的问题：安卓端的产品长什么样——登录页、主界面（选音源、开听）、悬浮字幕叠在别人的直播上、常驻通知、顶号 / 满员 / 断网到了手机上是什么体验。**不是正式客户端，也不代表安卓端已立项**：立项闸门是真机抓音验证，见 `docs/后续.md` 的「移动端」一节。验证完就丢。

## 怎么开

双击 `index.html`（Chrome / Edge），无需构建、无依赖、不联网。整个视口是一台模拟安卓手机。

## 舞台是什么

手机里有三个地方，导演台或桌面图标切换：

1. **桌面**：启动器。「看播」（别人的直播 App，竖屏全屏 + 弹幕 + 点赞栏）和本产品的图标能点开，其余是布景。**看播不归本产品**。
2. **看播**：观众正在看的外语直播。本产品在这里只露一处——**悬浮字幕窗**，叠在直播画面上，可拖，点一下回本产品。
3. **本产品 App**：登录页（登录注册同一屏）、主界面（音源、字幕模式、开听 / 停止）、个人中心（改密码）。

系统层的三处也是产品的脸：**状态栏的投屏小标**（在听时长亮）、**常驻通知**（通知抽屉最上面，带停止）、**横幅通知**（顶号 / 满员 / 断网时滑下来）。状态栏点一下开 / 关通知抽屉；底部手势条点一下回桌面。开听要先过**系统弹的媒体投影授权**——那是安卓的闸，不是我们画的。

## 怎么用

1. 默认停在本产品登录页（导演台「以已登录进入」可跳过）。登录，选音源，按开听。
2. 过系统授权后自动跳进看播，字幕按第一形态的规则上屏：草稿长字 → 定稿 → 切条 → 静默约两秒撤条。
3. 面板放后台，状态不丢：回到本产品 App 时按当下状态显示——在听还是停止、被顶还是满员，回到哪一页就停在哪一页。
4. 导演台按场景：英语 / 日语、连珠炮硬切、静默撤条、很久没人声、音乐；按事件：**顶号**（已在别处开听）、满员、断网、抓不到声音、闪断自动再开。
5. 舞台切「桌面」看悬浮字幕叠在别的层上的样子；切「本产品 App」看字幕在自己界面里藏不藏（现在是藏，未拍板）。

## 已定的（照词库、spec 和 ADR 做）

- 字幕条规则与第一形态完全相同：一条、草稿可中途改、定稿不再改、下一条立刻挤掉不淡出、静默约两秒撤条、默认双语可切仅原文 / 仅译文。
- 手机版只做托管听译：登录才解锁，本机听译只在电脑上（spec v2「两边各干什么」）。
- 同一账号同时只能一路在听，不分端：手机开了顶掉电脑，电脑开了顶掉手机（ADR 0033）。
- 被顶提示就是「已在别处开听」，不点名端；被顶后停听撤条，不再自动开回来。
- 多端可以同时登录；改密码后其它端的登录作废，本机还登着（ADR 0028）。
- 满员：新的开听被拒并说明，已开听的不受影响。
- 真断网：停听并告知，不自动重开；短闪断：自动再开。
- 音不落盘。

## 原型里是建议、没拍板的

- 产品名沿用「直播同传」（桌面原型也这么叫，正式名未定）。
- **音源在手机上的形态**：按 App 选（看播 / 短视频）加「全部可抓的声音」兜底——这只是纸面方案，真机上能不能按 App 抓、抓得到哪些 App，待抓音验证。
- 开听后自动跳去看播；悬浮字幕点一下回本产品；字幕在本产品自己的界面里藏起来。
- 常驻通知和横幅通知的文案；改密码三栏布局；字号三档。
- 字幕样式自定义：颜色三选（白 / 黄 / 青）、半透明黑底衬、字号三档；位置自由拖动，拖到哪记到哪，可一键回默认。长按字幕直接换样式没画，样式只在面板里改。
- 系统授权对话框的文案是安卓定的，原型画的只是示意；「显示在其他应用上层」的权限引导没画，等抓音验证一起定。
- 记住我只做了视觉，登录态不做真的。

正式版的记忆（音源、字幕模式、字号）在本原型里只活在内存，刷新页面重来。
