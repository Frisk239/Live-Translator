# 直播同传工具 · 可交互原型（扔掉用）

回答的问题：控制面板长什么样（三个变体）、字幕窗的手感（草稿长字 → 定稿 → 切条 → 静默约两秒撤条）、失败态长什么样。**不是正式客户端**，不接真听译，验证完就丢。

## 怎么开

双击 `index.html`（Chrome / Edge），无需构建、无依赖。直播画面就是渐变底，不联网也一样（占位图压在渐变底下，看不到）。

## 舞台是什么

整个浏览器视口是一台模拟电脑：壁纸、桌面图标（可选中）、能拖动能最大化能缩放的浏览器窗口（里面是别人的外语直播 + 滚动聊天栏）、Windows 风任务栏（开始菜单能点开、时钟带日期）。**直播画面不归本产品**。本产品只出现在三处：

1. **托盘**：任务栏右下的小图标。左键开 / 藏控制面板，右键出菜单（开听 / 停止、开机自启、退出）。
2. **控制面板**：托盘飞出的面板，标题栏可以拖着走。选音源、字幕模式、字号、开机自启、开听 / 停止都在这里。
3. **字幕窗**：默认屏幕靠下居中、离开任务栏一截。hover 出现原型把手：拖动移位置、右下角改大小。正式版无框、字穿透、跟屏幕不跟窗口。

## 怎么用

1. 点托盘图标开控制面板，选音源，按开听。
2. 顶部小胶囊（原型工具条）或 ←/→ 切三个控制面板变体（A 紧凑单列 / B 双栏带电平 / C 状态卡加折叠），地址栏 `#a #b #c` 刷新保持。
3. 顶部胶囊里的「导演台」或屏幕右缘的拉手打开抽屉，点场景：换说话内容、演示硬切 / 静默撤条 / 各类失败态、重置首次打开的模型下载。抽屉开着会盖住右下角面板，用完收起。
4. 关面板（点 ×）只藏面板，开听不停；停止才撤字幕窗；托盘退出是整份关掉（浏览器窗口还在，因为那不归本产品）。

## 已定的（照词库和 ADR 做）

一条字幕条、草稿可中途改、定稿不再改、下一条立刻挤掉上一条不淡出、静默约两秒撤条、默认双语可切仅原文 / 仅译文、停止撤字幕窗、关面板只藏、托盘退出整份关、上次音源进程没了不改用系统混音。

## 原型里是建议、没拍板的

产品名「直播同传工具」、字号三档、面板默认变体 A、开听中换音源立刻切、双语原文上译文下、草稿降透明度加行尾竖标、首次下载进度放在开听键位置、弱机器只提醒不拦、失败文案、托盘菜单项。

正式版的记住音源和设置在本原型里只活在内存，刷新页面重来。
