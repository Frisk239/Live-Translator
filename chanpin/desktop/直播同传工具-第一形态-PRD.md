# 直播同传工具 · 第一形态 PRD

状态：可开发说明。**已定**部分只来自 `CONTEXT.md` 词库、`docs/v1-形态.md`、ADR 0001 / 0002 / 0003 / 0006；**建议**部分来自 2026-08-17 的可交互原型（`chanpin/desktop/prototype/`），未经拍板，开发前需逐条确认，不确认就照默认值做并在验收时复核。词只用 `CONTEXT.md` 的。

## Problem Statement

观众在自己电脑上看别人的英 / 日 / 韩直播，听不懂，也来不及查。平台自带的字幕多数没有或不准，能用的又要装一堆东西、配一堆参数。观众要的是：开着直播，屏幕上多一行跟嘴走的简体中文，别的不用管。

## Solution

Windows 观众端，只用本机听译。产品在托盘；点开控制面板，从正在出声的应用程序里选一个音源（或系统混音兜底），按开听。字幕窗出现在屏幕靠下居中：透明、置顶、没有按钮、字穿透，可拖、可改大小。同一时刻只亮一条字幕条：先草稿后定稿，切条跟嘴，静默约两秒撤条。源语言自动认，只认英 / 日 / 韩，译成简体中文。

## User Stories

1. 作为观众，我想点托盘图标就打开控制面板，这样不用在桌面找窗口。
2. 作为观众，我想在控制面板里看到正在出声的应用程序列表，这样能选对要听的那一路声音。
3. 作为观众，我想要系统混音兜底，这样拆不开的出声应用也能听。
4. 作为观众，我不想开听前先选源语言，这样少一步配置。
5. 作为观众，我按开听后字幕窗立刻出现，这样知道已经在听了。
6. 作为观众，我想看到当前字幕条的字往外长，这样不用等整句说完才见字。
7. 作为观众，我接受草稿中途改字，这样能换到更准的定稿。
8. 作为观众，我想切条跟上嘴，这样字和说话对得上。
9. 作为观众，我想连珠炮时也硬切换条，这样画面不糊成一坨。
10. 作为观众，我想没人说话约两秒后字幕条直接拿掉，这样画面回到干净。
11. 作为观众，我想默认双语（原文一行、译文一行），这样能对得上原话。
12. 作为观众，我想切仅原文或仅译文，这样按自己习惯看。
13. 作为观众，我想调字幕字号（建议），这样远的近的屏幕都看得清。
14. 作为观众，我想拖字幕窗位置、改大小，这样不挡画面关键处。
15. 作为观众，我想字幕窗字穿透，这样点到的是下面的直播。
16. 作为观众，我点面板 × 只藏面板，这样收走面板不影响听。
17. 作为观众，我按停止就撤字幕窗，再开听才回来，这样画面完全归我。
18. 作为观众，我从托盘退出是整份关掉，这样不留后台。
19. 作为观众，我想音源和选择下次打开还在，这样不用重选。
20. 作为观众，上次那个进程不在了，我想停在控制面板里再选，不改成系统混音，这样不会听错路声音。
21. 作为观众，我勾开机自启只把产品拉到托盘，不自动开听，这样开机不吵。
22. 作为观众，第一次打开模型要下载，我想先看壳、面板能用，这样不用干等（建议）。
23. 作为观众，我机器算力弱时想看到提醒但仍能用，这样心里有数不被拦（建议）。
24. 作为观众，听到的不是英 / 日 / 韩时，我想在字幕位置看到一句提示，这样知道为什么没字（建议）。
25. 作为观众，开了听但没人声时，我想在控制面板看到「还没听到人声」，这样知道它在工作（建议）。
26. 作为观众，音源抓不到声音时，我想在面板里看到原因和一条改用系统混音的出路，这样自己能救（建议）。
27. 作为观众，听译挂了时，我想收到托盘通知、面板里一键重试，这样不用重启产品（建议）。
28. 作为观众，开听当中换音源，我想立刻切到新音源不停，这样不打断看（建议）。
29. 作为观众，开听当中改字幕模式 / 字号，我想立刻生效，这样随手调（建议）。
30. 作为观众，我想托盘右键就有开听 / 停止和退出，这样不开面板也能操作（建议）。

## Implementation Decisions

### 已定（照 ADR 和形态做，不改）

- **音源按进程选**（ADR 0001）：Windows 按进程抓音频；同一个浏览器里的两个直播拆不开，写进产品说明；不按窗口、不按直播间选；系统混音兜底。
- **切条跟嘴**（ADR 0002）：口气停顿 → 句末标点 → 从句边界 → 逗号 / 顿号 → 字数或时长硬切。观众不能调快慢。
- **先草稿后定稿**（ADR 0003）：当前条切条前跟着往外长、中途可改；切条时冻住；下一条挤掉上一条；不往上滚历史。
- **只做本机听译**（ADR 0006）：壳只有一份，听译以后可换本机或托管；第一版只接本机；插件不做。
- **壳的三件事**：托盘、控制面板、字幕窗。关面板 = 藏；停止 = 撤窗；托盘退出 = 整份关。没有「在听但字幕藏着」的状态，字幕窗上没有叉、没有工具条。字平时穿透；鼠标移到字幕条上才出现细把手，用来拖位置、改大小，松手后把手消失、继续穿透。
- **默认双语**，可切仅原文 / 仅译文；源语言自动认，MVP 只认英 / 日 / 韩 → 简体中文。
- 代码只进 `desktop/`，产品物只进 `chanpin/desktop/`。不引用已过时的 ADR 0004。

### 接缝

壳与听译之间只有一条缝：壳把选定的音源交给听译，听译吐「草稿 / 定稿 / 提示」事件。壳不关心听译怎么实现；听译不关心字怎么画。第一版接本机听译，第二形态在同一缝上换托管听译，壳不改。测试就打在这条缝上（假听译回放时间轴）。

### 状态机（原型验证过，直接沿用）

```
未开听 idle ──开听──▶ 在听 listening ──停止──▶ 未开听
   │                    │
   │首次：下载中          ├──音源抓不到──▶ 出错 failed ──重试/换音源──▶ 未开听/在听
   ▼ downloading ──完成──▶ 未开听          └──听译挂了──▶ 出错 failed ──重试──▶ 在听
```

托盘退出不在状态机里：整份关，下次从托盘进来，回到上次的选择。

### 十二条建议（原型带来，未拍板；默认值就是原型行为）

1. **产品名**：直播同传工具。托盘悬停也用这六个字。
2. **控制面板项**：状态行、音源（刷新、进程名 + 友好名、系统混音置底、上次选择带选中态）、字幕模式、字幕字号、开机自启、开听 / 停止主按钮。不确认就按变体 A（紧凑单列）做。B / C 只留在原型里对照。
3. **第一次打开**：面板先能用（能看壳、能选音源），下载进度放在开听键的位置，约数文案（「约还需 X 分钟」），装完托盘通知。不弹独立安装向导。
4. **机器门槛**：弱机器（如核显笔记本）只在面板给黄字提醒「字幕可能出现得慢一些，但还能用」，不拦截、不给设置项。
5. **音源列表**：显示进程名 + 友好名；正在出声的排前面；没人出声时给空态文案 + 刷新按钮；变体 B 里每行带音量电平帮助确认选对。
6. **开听中改设置**：改音源立刻切到新音源（字幕窗短提示「已换音源，继续在听」）；改字幕模式、字号即时生效；都不要求先停止。
7. **草稿和定稿的区分**：草稿整行约 66% 透明度、行尾一个呼吸竖标；定稿满透明度、竖标消失。不用颜色区分（避免像报错）。
8. **双语上下与折行**：原文一行在上（约 0.62 倍字号），译文一行在下；译文约 16 到 20 字起折行，随字号联动；每行最多两折，再多交给切条。
9. **硬顶数字**：译文约 16 个汉字或时长约 6 秒，先到为准。写进实现当常量，第一版不给观众调。
10. **托盘菜单**：左键单击 = 开 / 藏控制面板；右键菜单 = 打开控制面板、开听（在听时为停止）、开机自启（勾选）、退出。
11. **失败态**（四类，都不弹模态框）：
    - 不是英 / 日 / 韩或纯音乐：字幕位置出一条提示行「听到声音，但不是英 / 日 / 韩的人声」，几秒后拿掉；面板状态行同步「没听出英 / 日 / 韩的人声」，开听保持。
    - 没人声：画面不出现任何东西；面板状态行「在听 · 还没听到人声」。
    - 音源抓不到（权限不够）：停止开听，面板内联红字 + 两个出路按钮（改用系统混音 / 重试）。
    - 听译挂了：字幕窗撤掉，托盘通知「听译停了」，面板状态行「点开听重试」，重试直接回在听。
12. **字号 / 字体 / 描边**：字号三档（小 / 中 / 大）进面板；字体和描边不进设置，固定白字、黑描边、软投影，跟电影字幕一个路数。

## Testing Decisions

- 测外部行为，不测内部：壳层测试全部打在壳↔听译的缝上，用假听译回放原型的同款时间轴（`prototype/app.js` 里的 SCRIPTS 就是现成用例数据：草稿长字、中途改、定稿、gap 演示撤条、连珠炮硬切）。
- 必须过的场景清单（对应原型的导演台）：开听→草稿→定稿→切条循环；停两秒撤条；连珠炮硬切；换音源立刻切；改模式 / 字号即时；四类失败各自的出口；首次下载完能开听；上次音源退出不改系统混音；停止撤窗；托盘退出整份关。
- 真听译单独评测两件事：切条时机像不像人切的、草稿到定稿的延迟。数字见 `chanpin/desktop/开发入口.md`。不合预期调听译，不改壳。
- 原型本身是验收基准：`chanpin/desktop/prototype/`，双击 `index.html`。
- 引擎、系统门槛、模型下载见 `docs/adr/0007-local-listen-translate-stack.md` 和 `chanpin/desktop/开发入口.md`。

## Out of Scope

- 托管听译、账号（第二形态，见 `docs/v2-形态.md`）
- 浏览器插件（不做，见 ADR 0006）
- 配音、切条速度调节、隐身听、LLM 润色（见入口文档「不做」清单）
- 给主播往直播画面里叠字幕（本产品只给观众自己看）
- 拆同一个浏览器里的两个直播（Windows 上限，ADR 0001）
- 多显示器记忆、字幕窗记忆之外的窗口管理细枝末节（字幕窗位置和大小要记，其余不管）
