读完这个和 PRD，可以写 `desktop/`。词用 `CONTEXT.md`。壳按原型验收。

## 必读

1. `CONTEXT.md`
2. `chanpin/desktop/直播同传工具-第一形态-PRD.md`
3. `docs/v1-形态.md`

## 听译（PRD 里没写死的，这里写死）

| 项 | 定什么 |
|---|---|
| 系统 | Windows 10 2004（19041）及以上，或 Windows 11。进程音源靠 Application Loopback。 |
| 识别 | SenseVoice-Small，sherpa-onnx。英日韩粤都能认，自动认源语言。 |
| 翻译 | OPUS-MT：`en-zh` / `ja-zh` / `ko-zh`，CTranslate2 int8。 |
| VAD | Silero，32ms 帧。 |
| 切条 | ADR 0002。硬顶：译文约 16 字或约 6 秒，先到为准。 |
| 不上 | LLM、Whisper-medium/large 当默认、配音、观众填 key。 |
| 模型从哪来 | 第一次打开后台下载。国内优先 ModelScope，失败再 HuggingFace。进度在开听键位置（PRD 建议 3）。 |
| 弱机器 | 能开，面板黄字提醒可能慢。不拦截。 |

## 壳和听译的缝

壳交出选中的音源；听译回事件：草稿、定稿、提示（不是英日韩 / 没人声 / 抓不到 / 挂了）。假听译能回放原型时间轴，壳的测试打在这条缝上。

## 延迟验收

- 开口到草稿上屏：目标 1 秒内，超过 2 秒算不过。
- 切条到定稿冻住：再加不超过 0.5 秒（本机翻译）。
- 不合先调听译，不改字幕窗规则。

## 技术栈（ADR 0008）

- 壳：Tauri 2 桌面应用（独立窗口 / 托盘 / 字幕窗，不是浏览器标签）。
- 听译：本机 Python 进程。sherpa-onnx + CTranslate2。
- 缝：壳抓 PCM，本机 HTTP/WebSocket 交给听译，回草稿 / 定稿 / 提示。
- 不用 Electron、WPF、PyQt。本机需 Node.js、Rust（编 Tauri）、Python。

## 代码放哪

只进 `desktop/`。不要建 server/client。不要改 `reference/`。
